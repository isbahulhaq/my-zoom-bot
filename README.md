# Zoom Meeting Bot (Flask + Playwright + Chromium + New UI)

A powerful multi-bot Zoom auto-joiner built using **Flask**, **Playwright**, **Chromium**, and a **PRO-level frontend Dashboard**.

This version includes:
✔ New UI (Login + Dashboard + Name Type Feature)  
✔ Full Dockerfile support (Chromium + Gunicorn)  
✔ Render deployment support  
✔ Multi-bot Zoom joining  
✔ Random name generator + Name Type selector  
✔ /start → single bot + wait  
✔ /join → multi bot launcher  
✔ /end → instantly stop all bots
